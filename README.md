# Mitsubishi Electric — Demand Forecasting Console (v3.5)

Single-file dashboard (`index.html`) with forecast data embedded. Hosted with GitHub Pages.

- Needs an internet connection to load fonts, Chart.js and the Excel-export library from public CDNs.
- Edits made in the page (targets, stock levels, notes) are saved in the visitor's own browser only.
